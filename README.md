# מדריך SynthWave — הדרכת זיהוי מדיה סינתטית (עברית)

אתר לימוד פנימי (עברית) המבוסס על שני פרסומים של INTERPOL Project SynthWave:

> INTERPOL (2026). *[Project SynthWave] Global Guideline &ndash; False Facades*.
> מדריך הנחיה גלובלי בנושא זיהוי ואימות מדיה סינתטית (Deepfakes / Shallowfakes)
> עבור גורמי אכיפת חוק. (8 פרקים + מילון מונחים)

> INTERPOL (2025). *[Project SynthWave] Research Study &ndash; Forged Realities*.
> מחקר משלים על איומי מדיה סינתטית בדרום-מזרח אסיה ותגובת גורמי אכיפת החוק
> באזור (Brunei, Cambodia, Indonesia, Laos, Malaysia, Philippines, Singapore,
> Thailand, Viet Nam). (6 פרקים)

שני המסמכים פורסמו על ידי אינטרפול בדף הפרויקט:
https://www.interpol.int/en/How-we-work/Innovation/Projects/Project-SynthWave

## שימוש: פנימי בלבד — הגבלת הפצה של אינטרפול

המסמך המקורי כולל הבהרה מפורשת: אף שאינו מכיל מידע מודיעיני, הוא מוגדר
כחומר **רגיש**, המיועד **לשימוש גורמי אכיפת חוק רשמיים בלבד**, ואסור
בהפצה נוספת ללא **אישור בכתב מאינטרפול**. בהתאם לכך, ובדומה לפרויקט
האחות [`ai-face-detection-training`](../ai-face-detection-training):

- האתר **נשאר unlisted**: לא מקודם בגוגל (`robots.txt` + `<meta name="robots"
  content="noindex, nofollow">` בכל עמוד), ולא מקושר מבחוץ.
- מיועד ללמידה פנימית של צוות המעבדה/החטיבה בלבד.
- **אין לפרסם את האתר, את התרגום, או קטעים ממנו באופן פומבי** ללא אישור
  בכתב מאינטרפול.

## על סקריפט ההרכבה

**לא נדרש build step כדי לצפות באתר** — כל קבצי ה-HTML/CSS/JS כבר קיימים
ומוכנים, בדיוק כמו בפרויקט האחות. `generate_site.py` הוא כלי עזר חד-פעמי
(פנימי, לא חלק מהאתר) ששימש להרכיב את דפי הפרקים מתוך `hebrew_translation.md`.
יש להריץ אותו מחדש רק אם:

- מעדכנים את `hebrew_translation.md` (למשל תיקון תרגום), או
- רוצים לשנות את התובנות/המבחנים/הכרטיסים המוגדרים בתוך הסקריפט עצמו.

```bash
python generate_site.py
```

הסקריפט דורש את חבילת `markdown` (`pip install markdown`).

## הרצה מקומית

אין build step לצפייה. פותחים `index.html` ישירות בדפדפן, או מריצים שרת
סטטי פשוט (מומלץ, כדי שהתפריט הנייד וה-iframe של ה-PDF יעבדו כראוי):

```bash
python -m http.server 8421
```

## פרסום

בהיעדר שרת פנימי, האתר מתארח כרגע ב-GitHub Pages (ריפו **ציבורי** ברמת
הגישה הטכנית, אך **unlisted**: לא מקודם, לא מקושר מבחוץ, וחסום מאינדוקס
חיפוש בכל עמוד — `robots.txt` + `<meta name="robots" content="noindex,
nofollow">`). זו החלטה מודעת, בדומה לפרויקט האחות: **הקישור מופץ אך ורק
לחברי החטיבה**, ואין לשתף אותו הלאה מחוץ לארגון. אם וכאשר יתקבל אישור
בכתב מאינטרפול, או תהיה גישה לשרת פנימי, ניתן לעבור לאירוח מוגבל-גישה
אמיתי.

1. ודאו שהריפו הוגדר Public: Settings → General → Danger Zone → Change
   repository visibility.
2. הפעילו Pages: Settings → Pages → Source: Deploy from a branch →
   Branch: `main`, Folder: `/ (root)` → Save.
3. אחרי דקה-שתיים תופיע הכתובת למעלה באותו עמוד (בפורמט
   `https://<username>.github.io/interpol-synthwave-guideline/`).
